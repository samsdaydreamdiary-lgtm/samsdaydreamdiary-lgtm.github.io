Privacy Policy

Sam Upload Tool · Last updated: November 3, 2026

This policy explains how Sam Upload Tool ("the tool") handles information. The tool is a private program used only by the owner of the Sam's Daydream Diary YouTube channel to upload videos to that channel.

YouTube API Services

The tool uses YouTube API Services. Your use of the tool is also subject to the Google Privacy Policy and the YouTube Terms of Service.

Information the tool accesses

  • With the account owner's permission, the tool requests the youtube.upload permission, which only allows it to upload videos to the signed-in YouTube channel.
  • It sends the video file, title, description and privacy setting that the owner chooses to YouTube.
  • It does not read, collect or store any other YouTube data, viewer data, comments, analytics or personal information.

How information is stored

The sign-in permission (an OAuth token) is stored only as a file on the owner's own computer. It is never sent to any server other than Google's, and is never sold, shared or used for advertising.

Sharing

The tool does not share any information with third parties. Uploaded videos are sent only to YouTube.

Cookies and tracking

The tool does not use cookies, analytics or tracking of any kind. This website does not either.

Removing access

Access can be revoked at any time from the Google security settings page. Deleting the token file from the computer also removes the tool's access.

Changes

If this policy changes, the updated version will be posted on this page with a new date.
