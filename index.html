Sam Upload Tool

Sam Upload Tool is a small, private program used only by the owner of the Sam's Daydream Diary YouTube channel. It uploads finished episodes from the owner's own computer to the owner's own YouTube channel, using the YouTube Data API.

The tool is not offered to the public, has no other users, and does not access anyone else's YouTube account or data.

The tool uses YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service.
